Бизнес-аналитик с практическим опытом обследования бизнес-процессов, анализа требований и проектирования решений для автоматизации информационных систем.

Более 11 лет опыта в сфере разработки программного обеспечения в роли технического писателя и руководителя команды технических писателей. Опыт включает взаимодействие с заказчиками, анализ требований, подготовку технической документации и сопровождение процессов разработки. В данном репозитории представлены проекты, демонстрирующие мои навыки в области бизнес-анализа.
