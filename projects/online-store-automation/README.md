# 🏗 Online Store Automation

## Project Overview

This project demonstrates a complete business analysis cycle for the automation of an online building materials store.

The project includes business process analysis, requirements engineering, solution design and preparation of project documentation.

---

# Business Goal

To automate the order processing workflow and reduce manual operations while improving customer experience.

---

# My Role

Business Analyst

---

# Responsibilities

- Domain analysis
- Business process analysis
- Stakeholder needs analysis
- AS IS process modeling
- TO BE process modeling
- Business requirements
- Functional requirements
- User Stories
- Use Cases
- UML modeling
- Interface prototyping
- Acceptance Criteria

---

# Business Result

The proposed solution allows:

- automated order processing;
- online payment support;
- stock availability verification;
- promo code processing;
- order status tracking;
- reduction of manual operations.
